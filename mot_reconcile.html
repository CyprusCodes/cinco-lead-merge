Rules used
  • Customer columns: KOÇAN SAHİBİ, SÜRÜCÜ İLETİŞİM NO, ARAÇ PLAKASI, ARAÇ MARKA/MODEL (or contact_name, phone, plate, model). Optional: email, vehicle_type.
  • Schedule columns: table (A, B, C or D), window_start, window_end, prefixes (comma-separated), optional note. One row per window. Tables B (trailers) and C (temporary plates) take number ranges such as 001-4222 R or ZT 001-2085.
  • Blank vehicle_type uses table A (commercial schedule). Table D: private car, motorcycle, hybrid, electric.
  • Specific rule first (AB 285 N → AB-N), then plain prefix (AB). Same plate and phone are merged; same plate with different phones are flagged.
  • The download's first sheet is in Campa's import format (name, phone, email, labels, then custom fields): only rows without an issue, one row per phone. Rows with an issue are on the "Back to garage" sheet.
